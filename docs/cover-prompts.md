# Cover-image prompts — project gallery (advertising banners)

بروميتات غلاف على شكل **بانر إعلاني / key visual تسويقي** لبطاقات `/projects` — منتج بطل +
عناصر العلامة طائرة + مساحة فارغة للعنوان + إضاءة إعلانية. **جاهزة فقط للتطبيقات التي أملك
لقطاتها الحقيقية** (مبنيّة على ألوانها وواجهاتها الفعلية). الثلاثة بلا لقطة (Mademoiselle / Eda /
Blatos) **لم أكتبها** حتى أرى لقطة. النسبة **16:10**.

**كيف تستخدمينها**
1. الصِقي البروميت كاملاً (كتلة واحدة) في المولّد. للـ Midjourney أضيفي `--ar 16:10`.
2. احفظي الناتج في `public/work/<slug>/cover.png` ثم شغّلي `node scripts/to-webp.cjs`.
3. أخبريني فأضبط `cover: "/work/<slug>/cover.webp"` على إدخال المشروع في `projectsIndex`.

**Negative prompt (لكل الصور):**
> text, words, letters, arabic gibberish, UI copy, watermark, logo, brand marks, clutter,
> harsh contrast, low quality, distorted phone, warped screen, extra fingers

> «بلا نص» مقصود: المساحة الفارغة في البانر تُترك خالية ونضيف العنوان الحقيقي لاحقاً (المولّدات
> تكتب حروفاً مشوّهة). التماسك بين البطاقات من **المعالجة** لا من توحيد اللون — كل علامة بألوانها.
